# Home WOD

CrossFit προπονήσεις στο σπίτι, με στόχο την απώλεια βάρους.

- **WOD generator**: διαλέγεις τον εξοπλισμό σου (kettlebell, air bike, διάδρομο, βαράκια έως 15 kg, λάστιχα), επίπεδο και διάρκεια, και παίρνεις έτοιμη προπόνηση: ζέσταμα, AMRAP / EMOM / For Time / Tabata / Intervals, finisher και αποθεραπεία.
- **Animated avatar** που δείχνει κάθε άσκηση (31 ασκήσεις με οδηγίες τεχνικής).
- **Timer**: AMRAP, EMOM, For Time, Tabata, Intervals, χρονόμετρο και αντίστροφη μέτρηση, με ηχητικά σήματα.
- **Μουσική**: γρήγορο άνοιγμα Spotify ή YouTube, με δικές σου playlist ανά πρόγραμμα.
- **Ιστορικό** προπονήσεων και εκτίμηση θερμίδων (αποθηκεύεται τοπικά στη συσκευή).
- Εγκαθίσταται στο κινητό σαν εφαρμογή και δουλεύει και χωρίς internet.

## Εγκατάσταση στο κινητό

- **iPhone (Safari):** Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».
- **Android (Chrome):** μενού ⋮ → «Εγκατάσταση εφαρμογής».

## Δημοσίευση με GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
Η σελίδα ανοίγει σε `https://<username>.github.io/<repo>/`.
